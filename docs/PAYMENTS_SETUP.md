# Настройка платежей — пошаговая инструкция

В боте три способа оплаты подписки. Все цены и настройки задаются **из самого бота**
(супер-админ: `/menu` → 🛡 Супер-админ), ничего не нужно менять в коде или передеплоивать.
Единственное исключение — API-ключи крипто-обозревателей: это переменные окружения (см. раздел «Крипта»).

| Способ | Что нужно регистрировать | Где включается |
|---|---|---|
| 💫 Telegram Stars | ничего | Супер-меню → 💫 Stars |
| 💳 Карта (эквайринг) | аккаунт у платёжного провайдера + токен из BotFather | Супер-меню → 💳 Карта |
| 🪙 Криптовалюта | ничего (нужны только свои кошельки + бесплатные API-ключи) | Супер-меню → 🪙 Крипто |

После успешной оплаты любым способом бот автоматически активирует подписку
на 30 дней (продление прибавляет срок) и привязывает чат к лицензии покупателя.

---

## 1. 💫 Telegram Stars — работает сразу

Ничего регистрировать не нужно. Stars — внутренняя валюта Telegram,
деньги копятся на балансе бота.

**Включить:**
1. `/menu` → 🛡 Супер-админ → 💫 Stars → «✏️ Изменить цену».
2. Отправьте число Stars (например `2500`). `0` — отключить.

**Как забрать деньги:** Stars лежат на балансе бота. Вывод — через
[Fragment](https://fragment.com) (нужен TON-кошелёк): Telegram позволяет
выводить звёзды ботов в TON через раздел «Мои боты» → бот → Balance,
минимум к выводу — 1000 Stars, холд 21 день. Либо тратить Stars на рекламу
в Telegram Ads без холда.

## 2. 💳 Оплата картой — что сделать вам

Карточные платежи в Telegram идут через **платёжного провайдера**. Telegram сам
не принимает карты — он передаёт платёж провайдеру, а деньги приходят на ваш
счёт у провайдера. Вам нужно один раз получить **токен провайдера** и вставить
его в меню бота.

### Шаг 1. Выберите провайдера

Полный список: https://core.telegram.org/bots/payments#supported-payment-providers

Практически:

- **ЮKassa (YooKassa)** — для приёма рублей, нужен ИП/ООО/самозанятость в РФ.
  Регистрация: https://yookassa.ru → «Подключить» → заполнить данные →
  подписать договор онлайн. Комиссия ~2.8–3.5%.
- **Stripe** — карты по всему миру (USD/EUR и др.), но НЕ работает с РФ-юрлицами.
  Регистрация: https://stripe.com.
- **Smart Glocal** — международный, часто используется с Telegram.
  https://smart-glocal.com.

> Не знаете что выбрать: аудитория в РФ → ЮKassa; международная → Stripe.

### Шаг 2. Получите токен в BotFather

1. Откройте [@BotFather](https://t.me/BotFather) в Telegram.
2. `/mybots` → выберите вашего бота.
3. **Bot Settings** → **Payments**.
4. Выберите провайдера из списка (например «ЮKassa»).
5. BotFather отправит вас в бот провайдера (например @YooKassaTestShopBot /
   @YooKassaShopBot) — там авторизуетесь в своём аккаунте провайдера.
6. После привязки BotFather покажет **токен** вида:
   - `1234567890:TEST:abcd...` — тестовый (деньги не списываются),
   - `1234567890:LIVE:abcd...` — боевой.

Сначала возьмите **TEST**-токен и проверьте всё, потом замените на LIVE.

### Шаг 3. Вставьте токен в бота

1. `/menu` → 🛡 Супер-админ → 💳 Карта.
2. «🔑 Ввести токен провайдера» → отправьте токен одним сообщением.
3. Выберите валюту кнопкой (RUB / USD / EUR) — должна совпадать с валютой
   вашего аккаунта у провайдера (ЮKassa = RUB).
4. «✏️ Изменить цену» → отправьте сумму, например `499` или `4.99`.

Всё — в `/buy` и в меню «Оплата» появится кнопка «💳 Картой».

### Шаг 4. Проверьте

С TEST-токеном: нажмите «💳 Картой», в форме оплаты введите тестовую карту
`4242 4242 4242 4242`, любой срок в будущем, любой CVC. Придёт
«✅ Оплата получена», подписка активируется.

### Важно знать

- **Токен хранится в состоянии бота** (Supabase), в env ничего добавлять не надо.
  В меню он показывается замаскированным.
- **Чеки (54-ФЗ, для РФ):** если у вас включена фискализация в ЮKassa, настройте
  в кабинете ЮKassa отправку чеков самой кассой («Чеки от ЮKassa»). Бот
  фискальные данные (provider_data) не передаёт — вариант «чек формирует
  магазин» работать не будет.
- **Минимальные суммы** задаёт провайдер (примерно от 100 ₽ / $1) — бот не даст
  поставить цену ниже.
- Деньги приходят на ваш счёт у провайдера, выводятся по правилам провайдера
  (ЮKassa — на расчётный счёт).

## 3. 🪙 Криптовалюта — кошельки + бесплатные ключи

Бот принимает: **TON**, **USDT** (TON / BSC / ERC-20 / TRC-20). Деньги приходят
**напрямую на ваши кошельки** — никаких посредников. Бот сам следит за
поступлениями через блокчейн-обозреватели и активирует подписку.

### Шаг 1. Кошельки

Нужен адрес в каждой сети, которую хотите принимать (достаточно одной-двух):

- **TON / USDT-TON:** [Tonkeeper](https://tonkeeper.com) или @wallet в Telegram → скопируйте адрес (начинается с `UQ`/`EQ`).
- **USDT BSC (BEP-20) / ERC-20:** [MetaMask](https://metamask.io) → адрес `0x...` (один и тот же для обеих сетей).
- **USDT TRC-20:** [TronLink](https://www.tronlink.org) → адрес `T...`.

### Шаг 2. API-ключи обозревателей (бесплатно)

Это единственное, что задаётся через переменные окружения (Railway →
Variables), потому что нужно до старта бота:

| Переменная | Где взять | Для каких сетей | Обязательно? |
|---|---|---|---|
| `TONAPI_KEY` | https://tonconsole.com → зарегистрироваться → API keys | TON, USDT-TON | нет (без ключа работает, но с жёстким лимитом запросов — для продакшена получите) |
| `ETHERSCAN_API_KEY` | https://etherscan.io/register → войти → API Keys → Add | **и ETH, и BSC** (один ключ, Etherscan API V2) | да, если принимаете USDT ERC-20 или BSC |
| `TRONGRID_API_KEY` | https://www.trongrid.io → Sign up → API Keys | TRC-20 | нет (без ключа лимиты меньше) |

`BSCSCAN_API_KEY` больше не нужен: BscScan влился в Etherscan V2, ключ
etherscan.io покрывает обе сети (оставлен как legacy-фолбэк).

После добавления переменных — передеплойте бота.

### Шаг 3. Настройка в меню

`/menu` → 🛡 Супер-админ → 🪙 Крипто:

1. «✏️ Изменить цену в USDT» → например `9.99` (цена в долларах; для оплаты
   в TON курс берётся автоматически с CoinGecko).
2. Режим:
   - **Дельта суммы** (по умолчанию, рекомендую) — один адрес на сеть, каждому
     счёту выдаётся чуть отличающаяся сумма (`…000123`), по ней бот понимает,
     кто заплатил. Просто вставьте по одному адресу на сеть.
   - **Уникальный адрес** — каждому счёту свой адрес из пула. Надёжнее
     идентификация, но надо заранее добавить несколько адресов в пул.
3. Вставьте адреса кнопками по сетям.

Готово: в `/buy` появится «🪙 Криптовалюта», пользователь выбирает сеть,
получает адрес и точную сумму, счёт живёт 30 минут, бот проверяет поступления
каждые 30 секунд и активирует подписку сам (частичную доплату тоже понимает).

---

## 4. Что покупатель видит

`/buy` (или `/menu` → Оплата):

- один способ включён → сразу счёт/адрес;
- несколько → меню выбора: «💫 Stars · 2500 ⭐» / «🪙 Криптовалюта · $9.99» / «💳 Картой · 499 ₽».

Цены трёх способов независимы — выставляйте каждый в своей валюте.

---

## 5. Если что-то не работает

- **Кнопки «Картой» нет** → в 💳 Карта должны быть заданы И токен, И цена (статус 🟢).
- **«Цена изменилась» при оплате** → вы поменяли цену, пока у пользователя висел старый счёт — пусть нажмёт /buy заново.
- **Крипто-платёж не засчитался** → проверьте, что задан ключ обозревателя нужной сети и адрес указан без ошибок; счёт истекает через 30 минут — «зависшие» поступления видно в логах (`crypto: orphan transfer`).
- **ЮKassa отклоняет платёж в тесте** → используйте именно TEST-токен и карту `4242 4242 4242 4242`.
