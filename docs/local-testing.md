# Локальный запуск для тестов

Как поднять свою тестовую копию бота на компьютере, не задев прод.

Идея та же, что раньше: отдельный тестовый бот в Telegram, **без Supabase**
(состояние живёт только в памяти и стирается при остановке — прод-данные не
трогаются), и **тест-режим с суффиксом**, чтобы в общих группах команды ловил
только тестовый бот, а не прод.

---

## Что понадобится

1. **Swift 6.2** — идёт вместе с Xcode 16+. Проверить в терминале:
   ```bash
   swift --version
   ```
   Должно быть `6.2` или новее. Если нет — обнови Xcode из App Store.
2. **Отдельный тестовый бот** в Telegram (токен, отличный от прода).
3. **API-ключи LLM** — те же, что на проде (OpenRouter + DeepSeek). Их можно
   переиспользовать, они не конфликтуют между инстансами.

---

## Шаг 1. Создать тестового бота в BotFather

Один токен Telegram может слушать только один запущенный инстанс. Поэтому для
локали нужен **свой** бот, отдельный от прод-бота.

1. Открой [@BotFather](https://t.me/BotFather) → `/newbot`.
2. **Username задай ровно `SwiftPT_test_bot`** (или, если занят, см. врезку ниже).
   Это важно: бот автоматически включает тест-режим, только когда его username
   именно `SwiftPT_test_bot` — проверка захардкожена в
   `Sources/LLM_chat_bot/App/LLM_chat_bot.swift:60`.
3. Сохрани выданный **токен** (`123456:ABC...`).

> **Если `SwiftPT_test_bot` занят и пришлось взять другое имя.**
> Тогда авто-суффикс не включится. Два варианта:
> - открой `Sources/LLM_chat_bot/App/LLM_chat_bot.swift:60` и впиши username
>   своего тестового бота вместо `"SwiftPT_test_bot"`; либо
> - тестируй в **личке** с ботом — там суффикс не нужен вообще (в приватном чате
>   бот один, конфликтовать не с кем). Суффикс важен только в общих группах.

---

## Шаг 2. Понять переменные окружения

Приложение читает конфиг **только из переменных окружения** (никаких `.env`
файлов оно не подхватывает). Полный список — в
`Sources/LLM_chat_bot/App/AppConfig.swift`.

### Обязательные (без них бот не стартует)

| Переменная | Что это | Для локали |
|---|---|---|
| `TG_BOT_TOKEN` | Токен **тестового** бота из BotFather | твой тестовый токен |
| `ROUTER_API_KEY` | Ключ OpenRouter | как на проде |
| `DEEPSEEK_API_KEY` | Ключ DeepSeek | как на проде |
| `COMPANY_CHAT_ID` | ID «компанейского» чата (целое число) | поставь `0` |

`COMPANY_CHAT_ID` локально ни на что не влияет — просто должен быть числом.
Ставь `0`.

### Намеренно НЕ задаём

- **`SUPABASE_URL` / `SUPABASE_SERVICE_KEY` / `SUPABASE_ANON_KEY`** — не указываем.
  Тогда бот пишет в лог `persistence disabled` и работает **в памяти**: история и
  настройки живут, пока процесс запущен, и исчезают при остановке. Прод-база не
  затрагивается. Это ровно то поведение, что было у тебя раньше без токена Supabase.
- **`UPDATE_MODE` / `WEBHOOK_PUBLIC_URL`** — не указываем. По умолчанию режим
  `auto`: раз публичного домена нет, бот сам выбирает **long polling** (getUpdates),
  а вебхук — только на проде (Railway). Polling — то, что нужно локально.
- **Крипто-ключи** (`TONAPI_KEY`, `ETHERSCAN_API_KEY`, …) — не нужны, если не
  тестируешь крипто-оплату.

### Полезная опциональная

| Переменная | Зачем |
|---|---|
| `LOG_LEVEL` | `info` (по умолчанию), `warn`, `error`. Для отладки оставь `info`. |
| `MAX_CONCURRENT_GENERATIONS` | Кап параллельных LLM-стримов (по умолчанию 64). |

## Шаг 3. Запуск

Два способа. Xcode — привычнее (ты так делал раньше). Терминал — быстрее.

### Вариант А. Xcode

1. Открой **`Package.swift`** в Xcode (двойной клик по файлу или
   `File → Open…` → выбрать `Package.swift`). Xcode сам подтянет зависимости.
2. Дождись окончания `Resolving Package Graph` / индексации.
3. Вверху выбери схему **`LLM_chat_bot`** и таргет **`My Mac`**.
4. Меню **Product → Scheme → Edit Scheme…** → слева **Run** → вкладка
   **Arguments** → секция **Environment Variables**. Нажми `+` и добавь:

   | Name | Value |
   |---|---|
   | `TG_BOT_TOKEN` | `<токен тестового бота>` |
   | `ROUTER_API_KEY` | `<ключ OpenRouter>` |
   | `DEEPSEEK_API_KEY` | `<ключ DeepSeek>` |
   | `COMPANY_CHAT_ID` | `0` |

5. **Close** → нажми **▶︎ Run** (Cmd+R).

Логи появятся в панели снизу (Console). Ищи строку
`Bot started as @SwiftPT_test_bot`.

> Переменные схемы хранятся в `.swiftpm/xcode/xcuserdata/…`, а это в `.gitignore` —
> токены **не попадут** в git. Безопасно.

### Вариант Б. Терминал

Из корня проекта:

```bash
TG_BOT_TOKEN='<токен тестового бота>' \
ROUTER_API_KEY='<ключ OpenRouter>' \
DEEPSEEK_API_KEY='<ключ DeepSeek>' \
COMPANY_CHAT_ID='0' \
swift run LLM_chat_bot
```

Первая сборка идёт несколько минут (качает и компилит зависимости), дальше — быстро.

Чтобы не вбивать ключи каждый раз, создай **`run-local.sh`** в корне (он уже под
`.gitignore` не подпадает — добавь его туда, см. ниже):

```bash
#!/usr/bin/env bash
export TG_BOT_TOKEN='<токен тестового бота>'
export ROUTER_API_KEY='<ключ OpenRouter>'
export DEEPSEEK_API_KEY='<ключ DeepSeek>'
export COMPANY_CHAT_ID='0'
export LOG_LEVEL='info'
swift run LLM_chat_bot
```

```bash
chmod +x run-local.sh
echo 'run-local.sh' >> .gitignore   # чтобы не закоммитить токены
./run-local.sh
```

## Шаг 4. Проверить, что работает

1. В логах должно быть:
   ```
   ... Supabase persistence disabled (missing SUPABASE_URL or key)
   ... HTTP server started on port 8000 (/health, /ready, /metrics, webhook)
   ... long polling started
   ... Bot started as @SwiftPT_test_bot
   ```
2. Проверка здоровья (в другом окне терминала):
   ```bash
   curl localhost:8000/health   # → OK
   curl localhost:8000/ready    # → ready
   ```
3. Напиши тестовому боту в **личку** — он должен ответить через LLM.

## Тест-режим и суффикс (главное отличие от прода)

Если тестовый бот называется `SwiftPT_test_bot`, каждый новый чат стартует в
**тест-режиме с суффиксом `1`**. Значит команды нужно писать **с суффиксом**:

```
/help1
/menu1
/model1
/setrole1 Ты — Дональд Трамп.
```

Голый `/help` тестовый бот проигнорирует. Смысл: в общей группе, где сидят и прод-,
и тест-бот, на `/help` ответит прод, а на `/help1` — только тест. Не мешают друг другу.

Дополнительно:
- Обращение по имени работает всегда: `/menu@SwiftPT_test_bot` (без суффикса).
- В **личке** суффикс не обязателен по смыслу, но авто-режим всё равно его включает —
  просто пиши с `1`, либо отправь `/testmode1` чтобы выключить тест-режим в этом чате
  (`/testmode` включает/выключает и показывает текущий суффикс).
- Команда `/testmode` выдаёт случайный суффикс 1–10 для конкретного чата — авто-`1`
  это дефолт для нового чата у тестового бота.

> Чтобы дёргать админ/суперадмин-команды и меню, твой Telegram-username должен быть
> **`maythe4th`** (root-суперадмин захардкожен в
> `Sources/LLM_chat_bot/App/LLM_chat_bot.swift`, поле `ownerUsername`). Если тестируешь
> с другого аккаунта — временно поменяй там username на свой.

## Остановка

- **Xcode**: кнопка ■ Stop (Cmd+.).
- **Терминал**: `Ctrl+C`.

Бот ловит SIGINT/SIGTERM и корректно завершается. Состояние (память-only) при этом
теряется — это нормально для теста.

## Частые проблемы

| Симптом | Причина / решение |
|---|---|
| `Missing env: TG_BOT_TOKEN` (или другой ключ) | Не задана обязательная переменная. Проверь схему Xcode / экспорт в шелле. |
| `COMPANY_CHAT_ID must be Int, got: …` | Значение не число. Поставь `0`. |
| Бот не отвечает, в логах `getUpdates error … 409 Conflict` | Тем же токеном уже кто-то поллит/висит вебхук. Убедись, что это **тестовый** токен и второй инстанс не запущен. Бот при старте сам делает `deleteWebhook`. |
| Отвечает прод-бот вместо тестового в группе | Пишешь голую команду. Добавляй суффикс: `/menu1`. |
| Тест-бот не включает суффикс | Его username не `SwiftPT_test_bot`. См. врезку в Шаге 1. |
| Долгая первая сборка | Норма: качаются `async-http-client` и `swift-nio`. Дальше быстро. |
| Порт 8000 занят | Задай другой: `PORT=8080` в переменных окружения. |

## Кратко (шпаргалка)

```bash
# 1. тестовый бот @SwiftPT_test_bot в BotFather → токен
# 2. из корня проекта:
TG_BOT_TOKEN='...' ROUTER_API_KEY='...' DEEPSEEK_API_KEY='...' COMPANY_CHAT_ID='0' \
  swift run LLM_chat_bot
# 3. пиши боту в личку; команды с суффиксом: /menu1
```

Supabase не задаём → память-only, прод не трогаем. Публичный URL не задаём →
long polling. Суффикс `1` → тест-бот не конфликтует с продом в общих группах.
